Open Golf's isolated NativeActivity bridge for the source-built JoyOrbit library. The engine and sanitized, source-described assets are built by scripts/prepare-golf.py and packaged by scripts/embed-golf.py; controller handling and app-private hole recovery are in the native adapter, with no external service or account.

The original MIT rules, physics and score files remain in the pinned source; JoyOrbit adds a GPL-3.0-or-later controller/save adapter. Java Back events enter a bounded atomic command mailbox consumed on the native render thread. A held Back returns on release so repeats cannot close the resumed library. The game is a separate `:golf` process, uses private atomic storage and retains malformed or oversized saves under distinct legacy names. Sound replacement includes a regression check against the patched, pinned Vorbis decoder; original source fonts and audio are excluded from the runtime payload.
